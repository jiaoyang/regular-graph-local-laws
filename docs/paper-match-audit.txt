AUDIT RESULT AND NECESSARY QUALIFICATION

The earlier public statements used finiteOmega without proving that the
original possibly-infinite-core reference maximum had the same value. That
was a real scope gap. It is now closed by a new actual infinite-core theory,
not by renaming a constant or adding an analytic certificate premise.

There is one unavoidable discrepancy with the UNCORRECTED PRINTED PAPER:
Definition2.6 asks for abs(G_ii(z)) bounded below by a positive constant
uniformly for ALL z in C+ (and2.9 supplies the constant upper bound).
For any actual bounded self-adjoint graph operator, abs(G_ii(iY))<=1/Y.
Thus a strictly positive uniform constant lower bound cannot hold as Y grows.
PaperDefinitionSanity.no_global_positive_diagonal_lower_bound proves this
obstruction in Lean, already for every fixed graph and vertex.

The project therefore explicitly corrects the global lower normalization to
abs(md(z))/C<=abs(G_ii(z)). It retains every possibly infinite core, every
upper-half-plane spectral parameter and the same entry/imaginary estimates.
PaperBoundedReference proves the usual positive constant lower bound on
EVERY fixed bounded spectral region. This is a source-definition correction,
not an assertion that the two printed/global formulas are literally equal.
Consequently no honest formalization can claim a literal identity with the
impossible uncorrected Definition2.6. The completed spectral conclusions
below use the explicit consistent corrected reference definition.
